> **"把 ROS2 拿掉，这个问题还成立吗？"**

> 不成立 → 才是 ROS2 问题，放这里。

（详细的两步判定法 + 实例，见父目录 `../README.md` §1.1）

## 0. 使用约定（以后新增笔记照这个来）

1. **一个「问题」一个文件**，命名用 `序号_主题.md`（如 `02_xxx.md`），**序号只增不减**
2. 每篇笔记固定结构（**顺序别变，方便对比复习**）：
   ```
   1. 一句话结论          ← 先给答案，别让人往下翻
   2. 现象 / 报错原文      ← 原样抄报错，方便以后搜索命中
   3. 为什么会这样（原理）
   4. 最小复现            ← 能独立跑、不依赖大工程
   5. 要不要 / 什么时候用  ← 判断标准，不是背结论
   6. 正确 ✗ 错误 对照
   7. 口诀 / 排查清单
   8. 关联知识（文件路径、命令、文档出处）
   ```
3. 报错原文**必须原样保留**（这样以后 Ctrl+F 搜报错就能找到笔记）
4. 涉及自己的代码时，**原文引用**，不要改写成"标准答案"——
   笔记是给自己看的，留着自己的思考痕迹才有用

## 3. 为什么笔记要放在这儿（而不是随手记在对话里）

- 对话会过期、上下文会满；**文件不会**
- 报错原文 + 最小复现 = 以后遇到同类问题**30 秒定位**
- 这些笔记以后能直接整理成：
  - 比赛报告里的「技术难点与解决」章节
  - 面试时的"我踩过哪些坑"素材
  - 公开作品包里的 `docs/`
